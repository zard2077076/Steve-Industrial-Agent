# Support

Before requesting help, run `/industrialagent version`,
`/industrialagent compatibility`, `/industrialagent diagnostics`, and reproduce
in a new disposable test world. Read `INSTALLATION.md`, `QUICK_START.md`,
`COMMAND_REFERENCE.md` and `KNOWN_ISSUES.md`.

Attach only the manually reviewed output of
`/industrialagent export-diagnostics`. Never attach a world, playerdata,
account data, private path, full modpack or third-party JAR.

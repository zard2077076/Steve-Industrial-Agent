# Security policy

`0.1.0-alpha.1` is experimental and only for disposable creative test worlds.
Do not report vulnerabilities by attaching a save, playerdata, credentials,
tokens, private logs or a third-party modpack.

Use a private security-reporting channel if the repository host offers one.
Include the Agent version, compatibility output, minimal reproduction and the
manually inspected redacted diagnostic ZIP. Do not publish a working exploit
that could mutate player worlds before maintainers can review it.

The project has no updater, telemetry or default network request. A report that
shows an unexpected network call, formal-world write, path escape, ownership
bypass or diagnostic data leak is security-sensitive.

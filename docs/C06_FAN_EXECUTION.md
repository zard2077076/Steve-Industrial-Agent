Status: WIP automated runtime gate passed; final integrated acceptance pending.

## Supported Phase I shape

- exact washing, smoking, haunting or blasting recipe;
- one item input and one guaranteed deterministic item output;
- owned encased fan, power, medium/support, iron-bar stop, side barriers,
  processing Depot and output chest;
- live airflow direction, reach, medium classification, kinetic state,
  input transformation and chest-output evidence;
- no arbitrary fluid routing, existing-factory attachment or player inventory.

The shared physical gate uses the safe washing route and observes real
`create:dough` output. RecipeManager identity and actual fan processing remain
authoritative; the handler never calls Create's processing method or constructs
the declared output.

## Dangerous-medium boundary

Water and lava remain behind the typed medium deployment policy and bounded
containment geometry. A Bot cannot enter the medium, stop or hot-air processing
cell. Unsafe Bot work is a typed unsupported result; Hybrid may route only that
exact sensitive task through Direct and records the fallback provenance.
Living-entity occupancy in a dangerous cell refuses before processing.

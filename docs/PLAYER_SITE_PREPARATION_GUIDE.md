# Player site preparation guide

1. Select an anchor and facing.
2. Select and preview a bounded region; verify coordinates and outline.
3. Confirm the region.
4. Preview the physical footprint and run the survey.
5. Review every obstacle class and protected item.
6. Approve only the safe group or named ordinary items.
7. Set an authorized salvage chest and start Direct, Bots or Hybrid clearing.
8. Watch real movement, collection and delivery; cancel on unexpected state.
9. Run the mandatory post-clearance rescan.
10. Start construction only after a fresh `PreparedConstructionSite` is shown.

Never continue after a stale-token, protected-obstacle, environmental-hazard or
formal-world refusal. Move/rotate the site or cancel.

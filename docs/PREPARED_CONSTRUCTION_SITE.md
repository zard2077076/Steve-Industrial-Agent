# Prepared construction site

`PostClearanceRescan` requires a fresh full-footprint snapshot. World,
dimension, selection and physical-plan identities must still match the initial
survey. Any remaining clearable, unknown or environmental obstacle refuses
preparation.

`PreparedConstructionSite` binds exact world/dimension, anchor, facing, plan
hash, clean snapshot hash, terrain task graph, salvage ledger, mutation
evidence, remaining protected findings and expiry. It is evidence for the
existing physical-plan/construction readiness path, not execution authority.

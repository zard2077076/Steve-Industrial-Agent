# Distribution boundary

The local Alpha candidate may contain only Steve Industrial Agent source/JAR,
project documentation, tests, CI configuration, checksums, dependency metadata
and path-free example configuration.

It must not contain the DeceasedCraft pack, Minecraft files, Forge installer,
Create or other mod JARs, third-party textures/models/audio, saves, worlds,
backups, playerdata, logs, crash reports, accounts, tokens or private paths.

The project license is the existing MIT `LICENSE`; no license choice is pending.
Third-party runtime dependencies are declarations only and are not bundled.

# Contributor Covenant Code of Conduct

This project adopts the Contributor Covenant version 2.1. Contributors must
provide a harassment-free, welcoming environment regardless of identity or
experience, use respectful language, accept constructive feedback and focus on
what is best for the community.

Unacceptable conduct includes harassment, threats, sexualized attention,
doxxing, publishing private information, and sustained disruption. Maintainers
may remove content or restrict participation in proportion to the incident.
Reports should use the repository host's private conduct channel when available.

Source and full standard text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
